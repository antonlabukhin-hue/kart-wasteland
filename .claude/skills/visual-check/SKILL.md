# Визуальная проверка

Пользователь смотрит визуал очень внимательно: направление машины, задвоенные зеркала, оторванные детали, звери сквозь машину, лишние столбы, раскладка меню. Не говорить «готово», пока сам не посмотрел скриншоты.

## Почему не панель браузера
Когда встроенная панель браузера скрыта, `requestAnimationFrame` не идёт — заезд замирает на отсчёте. Надёжный путь — скриптовый Playwright в Edge.

## Как снимать
1. `npm run build:test` → `dist-test/` (есть `window.__raceDebug`, `window.__artKit`).
2. Запустить превью: launch-конфиг `test-build` (порт 4184).
3. Скрипт положить **в `dist-test/`** (тогда резолвится `@playwright/test`), запускать `node dist-test/shot.mjs`:
   ```js
   import { chromium } from '@playwright/test';
   const b = await chromium.launch({ channel: 'msedge' });
   const pc = await b.newPage({ viewport: { width: 1366, height: 768 } });
   const phone = await b.newPage({ viewport: { width: 844, height: 390 }, isMobile: true, hasTouch: true });
   // ... goto http://localhost:4184/, вход (имя ≥ 3 символов), переходы по экранам, page.screenshot(...)
   await b.close();
   ```
   Скриншоты — в scratchpad, не в репозиторий.
4. Набор кадров:
   - все затронутые экраны меню на 1366×768 и 844×390 (+ портрет 390×844, если правка касается мобильного);
   - заезд: несколько кадров в движении (через `__raceDebug` можно читать состояние; автопилот — удерживать W, переотправлять keydown каждый тик, игра ставит паузу на blur);
   - машины/модели: студия `window.__artKit.buildCar(...)` — ~6 ракурсов (спереди, сзади, бока, сверху, 3/4).
5. Проверить: машина едет мордой вперёд, нет пересечений и висящих деталей, текст не обрезан, кнопки не перекрываются, тёмные/светлые зоны читаемы. Раскладка меню: панель справа (ближе к центру), живая 3D-машина слева.

## Отчёт
Показать пользователю ключевые скриншоты (SendUserFile) и перечислить, что проверено.
