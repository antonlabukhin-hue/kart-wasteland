# Архитектура модулей

## Фаза 1 — нарезка файлов
Модули в `src/` как отдельные файлы.

## Фаза 2 — подключено
Классы из монолита удалены. `window.createAnimalMesh` и `window.showAnimalShout` задаются в `main.js` после объявления функций: модули не видят функций из `main.js` напрямую.

## Фаза 3 — index.html разделён (текущее)
- стили: `css/style.css`;
- весь код игры: `src/main.js` (перенесён из `<script type="module">` как был);
- каталоги `CAMPAIGN_TRACKS`, `CAMPAIGN_STAGE_MODS`, `CAR_PRESETS`, `ANIMAL_TYPES`, `MAP_ANIMALS` — только в `data.js`, `main.js` их импортирует.

`index.html` подключает `./src/main.js`, тот импортирует остальное:

```js
import { SoundEngine } from './audio.js';
import { AnimalSpawner } from './animals.js';
import { ParticleSystem } from './particles.js';
import { CAMPAIGN_TRACKS, CAMPAIGN_STAGE_MODS, CAR_PRESETS, ANIMAL_TYPES, MAP_ANIMALS } from './data.js';
```

Функции, которые вызываются из разметки (`onclick="nextLorePanel()"` и т.п.), должны оставаться на `window`.

Vite собирает `index.html`, `css/`, `src/*` и three из `node_modules` в `dist/assets/` (importmap больше нет, версия three — в `package.json`).

## Фаза 4 — модули вокруг `main.js` (текущее)
Данные и чистая логика живут в отдельных модулях с юнит-тестами (`tests/unit`), `main.js` — склейка с игровым циклом и DOM.

| Модуль | Что внутри |
|---|---|
| `content.js` | контент мета-игры: карты, реплики злодея, достижения, трофеи, детали/краски, награды сезона, контракты, выкрики |
| `difficulty.js` | `DIFFICULTY_CONFIG` — параметры сложностей |
| `balance.js` | интерполяция «сложных» глав кампании |
| `tracks/layouts.json` + `track-layout.js` | раскладка участков (разломы, арки, сцена карты) и её проверка |
| `setpieces.js`, `mapevents.js` | меши участков и сцен карт |
| `boss.js`, `boss-intro.js` | модели боссов; карточка представления и фазы 2 |
| `cars.js`, `upgrades.js` | модели машин, прокачка и её видимые детали |
| `campaign-stars.js`, `chapter-tasks.js`, `tutorial.js` | звёзды, задания глав, подсказки тренера в главах 1–3 |
| `endless.js` | «Звериный час»: волны, очки, рекорд |
| `ghost.js` | призрак лучшего заезда: запись и воспроизведение |
| `audio.js`, `map-audio.js` | звук; тема карты (темп трека + процедурный фон) |
| `settings.js` | настройки игрока |
| `profile.js` | профили и сохранения, сезон и опыт, награды за заезд, ачивки, кампания, покупки в гараже (без DOM, хранилище — параметром) |
| `race-physics.js` | трамплины, прыжок, полёт, приземление |
| `boss-fight.js`, `boss-model.js` | правила боя (шкала тарана от уворотов, фазы, урон, арена); модель босса (тело, 10 типов голов, броня) |
| `move-tutor.js` | стрелки движений — в начале заезда четыре действия по очереди; новичку 3 заезда, после обновления управления — всем ещё 2 |
| `near-miss.js`, `lane-assist.js` | «на волоске» за уворот в последний момент; доводка до центра полосы, когда отпустили руль |
| `director.js` | «режиссёр»: занятые отрезки трассы — крупное не рядом с крупным, преграды с отступом, звери не выбегают у событий |
| `traffic-signal.js` | перестроения попуток: поворотник и стрелка за 0.8 с, в полосу игрока — только издалека |
| `cars-extra.js` | диски машин «из кино» (свой рисунок у каждой, склеены по материалу), пороги и фирменные детали |
| `segments.js`, `biomes.js`, `curved-world.js` | ремонт / развилка / тоннель; смена окружения по ходу трассы и лес; изгиб дороги в шейдере |
| `gamepad.js`, `i18n.js` + `locales/en.js`, `analytics.js` | геймпад; английский интерфейс; локальный журнал событий |
| `run-metrics.js` | забеги бесконечной трассы → Supabase `run_events`: где и от чего кончаются, длина, пауза до «Ещё раз», вариант A/B (SQL — docs/METRICS.md §4) |
| `slipstream.js` | слипстрим: мешок за попуткой копит бак нитро, уход вбок в последний момент — «Рывок»; полный бак — нитро по кнопке (E / 🔥 / X на геймпаде); кнопка и шлейф воздуха |
| `fail-rules.js` | правило провала бесконечной трассы — A/B: «сердца» (5) или «ГАИ на хвосте» (2 сердца, погоня за любую аварию, ушёл — сердца полные); ?fail=hearts|chase |
| `hit-zones.js` | зоны столкновения: краем попутки или зверя — «задел» (скорость, множитель, толчок; в «ГАИ на хвосте» — погоня), по оси — авария |
| `threat-style.js` | язык угроз: четыре класса (преграда, тормозит, заносит, движется) — кольцо своего цвета под помехой впереди и свой звук |
| `animal-rules.js` | одно правило на вид зверя: курица мечется, медведь и слон встают посреди дороги, олень, кабан, носорог — напролом |
| `run-goal.js` | одна цель на итогах бесконечной трассы: что остановило, куда целиться (рекорд, соперник, задание), совет по классу угрозы |
| `yandex-save.js` | прогресс в аккаунте Яндекса (player.getData/setData): новее — главнее, после сохранения — отправка |
| `oncoming-lane.js` | «Встречка ×2»: левая полоса на участке — встречная (табличка, разметка, встречные машины), очки риска вдвое |

Правило для нового кода: модули получают состояние параметрами и возвращают результат, а не читают и пишут `window.*` — так их можно покрыть тестами. Старые глобальные флаги (`window.__inRace`, `window.__campaignTrackId` и др.) переносятся по мере выноса кода.

Дальше: меню и экраны, гараж, в перспективе — вынос `initGame` в `game.js`.

## Режимы — src/modes/
Режим заезда, который раньше жил внутри `initGame`, выносится в `src/modes/<режим>.js`. Общий движок заезда (физика, попутки, звери, подборы, HUD, итоги) остаётся в `main.js`.

| Модуль | Что внутри | Связь с main.js |
|---|---|---|
| `modes/infinite-run.js` | «Бесконечная трасса»: план кругов и узоры, уборка позади, «горячий старт», погоня ГАИ, цели на дороге, события пейзажей, «В ударе», «Разгон», смена пейзажа и рост сложности | `createInfiniteRun(ctx)` — один объект: сцена, списки заезда, фабрики предметов, геттеры состояния (z, скорость, аварии…), сеттеры (`setRamp`, `setTheme`, `addNitro`, `startLap`) |
| `modes/beast-hour.js` | «Звериный час»: старт и волны по сиду, карточка между волнами, итог волны, рекорд и «Звериный час дня», текст итогов, ссылка-вызов | `createBeastHour(d)` — `startRace`, `setMode`, `player`, `save`…; забег — в `window.__endless` (его читают тесты) |

Короткие переключатели режима в общем коде (`INF ? … : …`, `isEndlessMode()`) остаются в `main.js` — это настройки движка, а не логика режима.
