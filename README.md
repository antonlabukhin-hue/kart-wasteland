# 🏎️ Дорожный прорыв: Пустошь (kart-wasteland)

> Экспериментальная версия [«Дорожного прорыва»](https://github.com/antonlabukhin-hue/kart-racer): вместо попуток — разбитые машины, самолёты и военная техника на трассе, главная угроза — бешеные звери, гонится босс компании, раз в 3000 м — объезд по полю. Основная игра живёт и обновляется отдельно.

## Об игре

Лихие 90-е в 2037 году: курьер везёт антидот через Приморье, звери перебегают дорогу, заезд длится 1:30.

**Режимы**
- **Кампания** — 17 глав, у каждой свой босс, 3 звезды и 3 задания. Главы 1–3 — обучение с подсказками тренера.
- **Свободный заезд** — карта, погода (день / ночь / дождь) и сложность на выбор.
- **«Звериный час»** — бесконечный режим волнами: карты по кругу, зверей всё больше, аварии копятся, рекорд профиля.
- **Призрак** — полупрозрачная машина повторяет твой лучший заезд на этой трассе.

**Боссы** (в броне, три фазы)
1. Стреляет: увернись — после промаха он открыт 2 секунды, тарань.
2. Ставит баррикады в две полосы: проскочил в просвет — открыт.
3. В ярости бежит навстречу: уйди с полосы или прыгни на него с трамплина (×3).

Снаряд, встреченный на нитро, летит обратно. Кувалда на дороге пробивает броню. Не успел до конца арены — босс сбегает.

**Трассы**
- Дорога поворачивает и уходит на холмы («кривой мир»).
- По ходу трассы меняется окружение: город, тайга, промзона, свалка.
- Разломы во всю ширину с трамплином в одной полосе, арки с падающим грузом, сцены карт (поезд, пар, горящие шины).
- Ремонт дороги, развилка и тёмный тоннель.

**Машины и гараж** — Чебурашка (вёрткая), Нива (внедорожник), Волга (турбо). Прокачка за фишки: двигатель, коробка, шины, броня, нитро. Покраска и детали.

**Прочее** — геймпад, русский и английский интерфейс, настройки (громкость, графика, камера, тряска, призрак, повороты дороги).

## Управление

| Действие | Клавиатура | Геймпад | Телефон |
|----------|------------|---------|---------|
| Газ | `W` / `↑` | RT / A | Кнопка вперёд |
| Тормоз | `S` / `↓` | LT / B | Кнопка назад |
| Полоса влево / вправо | `A` `D` / `←` `→` | Стик / крестовина | Стрелки |
| Камера | `C` | Y | Кнопка камеры |
| Пауза | `P` / `Esc` | Start | Пауза |
| Выйти в меню | `Q` | — | Пауза → Меню |

В меню геймпадом: крестовина — выбор, A — нажать, B — назад.

## Быстрый старт

**Требования:** Node.js 22.12+ или 24 (проверить: `node -v`; на Node 20 тесты не запустятся; версия записана в `package.json` → `engines` и в `.nvmrc` для `nvm use`), браузер с WebGL.

```bash
git clone https://github.com/antonlabukhin-hue/kart-racer.git
cd kart-racer
npm install
npm run dev
```

Сайт собирается сам: на каждый пуш в `main` GitHub Actions прогоняет тесты, собирает игру и публикует `dist/` на GitHub Pages (`.github/workflows/deploy.yml`). Упали тесты — сайт не обновится, у коммита будет красный крестик.

Сборки для Steam (Electron) и телефонов (Capacitor) — в `desktop/` и `mobile/`, см. [`docs/RELEASE.md`](docs/RELEASE.md).

## Устройство кода

В `index.html` — разметка экранов, стили — `css/style.css`, код — `src/`. `src/main.js` связывает всё вместе: меню, экраны и игровой цикл (`initGame`). Логика и данные вынесены в модули с тестами: профили и сохранения (`profile.js`), физика прыжка (`race-physics.js`), правила боя с боссом (`boss-fight.js`), раскладка трасс (`tracks/layouts.json`) и другие.

Карта модулей — в [`src/ARCHITECTURE.md`](src/ARCHITECTURE.md). Все боссы на одном экране: `npm run dev` → `/tools/boss-gallery.html`, машины — `/tools/car-gallery.html`.

```text
kart-racer/
├── index.html            # разметка экранов и заставка
├── css/style.css         # стили
├── src/                  # код игры: main.js и модули
├── src/tracks/           # раскладка трасс в JSON
├── public/images/, music/ # картинки и музыка (копируются в сборку как есть)
├── tests/unit/           # модульные тесты (Vitest)
├── tests/e2e/            # игра в браузере на сборке для сайта (Playwright)
├── tests/e2e/scenarios/  # сценарии на тестовой сборке: боссы, прыжки, участки, режимы
├── desktop/, mobile/     # обёртки для Steam и телефонов
├── docs/                 # релиз, аналитика, ассеты, QA
└── tools/                # галереи боссов и машин для разработки
```

## Разработка

```bash
npm run dev          # игра с перезагрузкой при правках
npm run test:unit    # модульные тесты — секунды
npm test             # всё: модульные + браузерные (сами соберут игру)
```

Перед первым `npm test`: `npx playwright install chromium`. Если Chromium не скачивается, на Windows браузерные тесты идут в Microsoft Edge: `npm run test:e2e:edge`. Упавший тест оставляет скриншот в `test-results/`.

Браузерные тесты идут на двух сборках:
- `tests/e2e/` — ровно та сборка, что уходит на сайт;
- `tests/e2e/scenarios/` — тестовая сборка (`npm run build:test`): `?start=0.97` начинает заезд с 97% трассы, `window.__raceDebug` даёт тестам управлять заездом. Этот код помечен `import.meta.env.MODE === 'test'` и в сборку для сайта не попадает.

Аналитика — локальный журнал на устройстве, в консоли `__analytics.summary()`, см. [`docs/ANALYTICS.md`](docs/ANALYTICS.md).
