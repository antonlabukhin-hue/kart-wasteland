# QA / smoke-чеклист — Дорожный прорыв

Прогонять перед пушем в `main` и после деплоя Pages.

## 5 минут

1. **Заставка** → клик → профиль (имя ≥ 2 символов) → вход.
2. **Главное меню** — все карточки кликаются; «Звериный час» запускает волну 1.
3. **Кампания** — открытая глава стартует; закрытая с замком не стартует.
4. **Заезд** — отсчёт 3-2-1-GO; машина едет с клавиатуры / тача.
5. **Онбординг** (первый заезд) — подсказка внизу ~12 с, скрывается по клику/клавише.
6. **Звери** — перебегают; столкновение = авария (лимит 5).
7. **Боссы** (кампания) — перед выстрелом красное кольцо + звук windup ≥ 0.6 с.
8. **Пауза** P / кнопка → продолжить / в меню.
9. **Финиш** — плашка, кнопки «Ещё раз» / «Меню» нажимаются с первого раза.
10. **Прогресс** — после победы в кампании глава остаётся пройденной после F5.

## Консоль

- Нет красных `ReferenceError` / `update error`.
- Нет спама `menu music play blocked` на каждый кадр (допустимо 1–2 при автоплее).

## Мобильный

- Нет дублей «Назад / Меню».
- После первой гонки кампании остаются кнопки газа/полос.
- Камера и пауза на HUD работают.
